If the radius of a circle is a rational number, its area is given by a number which is:

若正有理数半径为 \(r\)，则圆的面积为 \(\pi r^2\)。因数 \(r^2\) 是非零有理数，而无理数 \(\pi\) 的非零有理数倍仍是无理数。

English（选项同上方）

Two equal circles in the same plane cannot have the following number of common tangents:

两个不同的等圆相交时有 \(2\) 条公切线，外切时有 \(3\) 条，相离时有 \(4\) 条。它们不能内切，因为内切要求圆心距等于两半径之差，即 \(0\)。圆心距为 \(0\) 时，两个等圆重合，并有无穷多条公切线。

English

Two distinct equal circles have \(2\) common tangents when they intersect, \(3\) when externally tangent, and \(4\) when disjoint. Thus exactly \(1\) common tangent is impossible, so the correct answer is A.

English（选项同上方）

\(\log p+\log q=\log(p+q)\) only if:

利用对数乘积法则，原方程化为 \(\log(pq)=\log(p+q)\)，所以两个正真数必须满足 \[ pq=p+q\text{。}\]因此 \(p(q-1)=q\)，得到 \(p=\frac{q}{q-1}\)。允许的取值满足 \(q\gt1\)，这也保证所有对数的真数为正。

Thus, the correct answer is D.

English（选项同上方）

Angle \(B\) of triangle \(ABC\) is trisected by \(BD\) and \(BE,\) which meet \(AC\) at \(D\) and \(E,\) respectively. Then:

三角形 \(ABD\) 与 \(EBC\) 的底边 \(AD\) 和 \(EC\) 位于同一直线 \(AC\) 上，所以从 \(B\) 到该直线的公共高给出 \[ \frac{[ABD]}{[EBC]}=\frac{AD}{EC}\text{。}\]又有 \(\angle ABD=\angle EBC\)，因为两者都是角 \(B\) 的三分之一。再用两边及其夹角表示同一个面积比，得到 \[ \frac{[ABD]}{[EBC]} =\frac{AB\cdot BD}{BE\cdot BC}\text{。}\]

Thus, the correct answer is D.

English（选项同上方）

If \(\dfrac{x^2-bx}{ax-c}=\dfrac{m-1}{m+1}\) has roots which are numerically equal but of opposite signs, the value of \(m\) must be:

交叉相乘，得到 \[ \begin{aligned} (m+1)x^2 &-(m+1)bx\\ &-(m-1)ax\\ &\quad{}+(m-1)c=0 \end{aligned}\text{。}\]绝对值相等、符号相反的两根之和为 \(0\)，所以 \(x\) 的系数为 \(0\)。因此 \[ m(a+b)+(b-a)=0\text{，}\]并且 \[ m=\frac{a-b}{a+b}\text{。}\]

因此，正确答案是 A。

English

Thus, the correct answer is A.
