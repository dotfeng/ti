1单选

一袋 \(350\) 克的咖啡豆说明上写着：正确冲泡一大杯手冲咖啡需要 \(20\) 克咖啡豆。用这袋咖啡豆最多可以正确冲泡多少大杯咖啡？

English（选项同上方）

The instructions on a \(350\)-gram bag of coffee beans say that proper brewing of a large mug of pour-over coffee requires \(20\) grams of coffee beans. What is the greatest number of properly brewed large mugs of coffee that can be made from the coffee beans in that bag?

每杯需要 \(20\) 克，因此 \(\frac{350}{20} = 17.5\)。半杯不能算作一杯，所以向下取整，最多能冲泡 \(17\) 大杯，正确答案是 B。

English

Each mug needs \(20\) grams, so we divide: \(\frac{350}{20} = 17.5.\) A half mug isn’t a mug, so round down. That leaves \(17.\) Thus, B is the correct answer.

2单选

Jerry 写下前 \(2025\) 个正平方数的个位数字：\(1\)，\(4\)，\(9\)，\(6\)，\(5\)，\(6\)，\(\ldots\)。他写下的所有数字之和是多少？

English（选项同上方）

Jerry wrote down the ones digit of each of the first \(2025\) positive squares: \(1,\) \(4,\) \(9,\) \(6,\) \(5,\) \(6,\) \(\ldots\) What is the sum of all the numbers Jerry wrote down?

\(n^2\) 的个位数字只取决于 \(n\) 的个位数字，因此序列每 \(10\) 项循环：\(1, 4, 9, 6, 5, 6, 9, 4, 1, 0\)。一个循环的和为 \(45\)。又 \(2025 = 202 \cdot 10 + 5\)，所以共有 \(202\) 个完整循环，再加上前五项，总和为 \(202 \cdot 45\) \(+ (1 + 4 + 9 + 6 + 5)\) \(= 9090\) \(+ 25 = 9115\)。因此正确答案是 D。

English

The ones digit of \(n^2\) depends only on the ones digit of \(n,\) so the list repeats every \(10\) terms: \(1, 4, 9, 6, 5, 6, 9, 4, 1, 0.\) One block sums to \(45.\) Now \(2025 = 202 \cdot 10 + 5,\) so we get \(202\) full blocks plus the first five terms: \(202 \cdot 45\) \(+ (1 + 4 + 9 + 6 + 5)\) \(= 9090\) \(+ 25 = 9115.\) Therefore, the answer is D.

3单选

一个类似帕斯卡三角形的三角形，第一行为 \(10\)，第二行为 \(10\) 后接 \(1\)。在之后的每一行中，第一个数是 \(10\)，最后一个数是 \(1\)，并且和标准帕斯卡三角形一样，行中每个其他数都是它正上方两个数之和。前四行如下图所示。

第 \(11\) 行所有数之和的各位数字之和是多少？

English（选项同上方）

A Pascal-like triangle has \(10\) as the top row and \(10\) followed by \(1\) as the second row. In each subsequent row the first number is \(10,\) the last number is \(1,\) and, as in the standard Pascal’s Triangle, each other number in the row is the sum of the two numbers directly above it. The first four rows are shown below.

What is the sum of the digits of the sum of the numbers in the \(11\)th row?

设 \(S_n\) 为第 \(n\) 行的和。第 \(n-1\) 行的每个数都会贡献到下一行的两个位置，而固定的边界数 \(10\) 和 \(1\) 正好补上边缘缺少的项。因此 \(S_n = 2 S_{n-1}\)（当 \(n \ge 3\)）。由 \(S_2 = 11\)，得到 \(S_n = 11 \cdot 2^{n-2}\)，所以 \(S_{11} = 11 \cdot 2^9 = 5632\)。其各位数字之和为 \(5 + 6 + 3 + 2 = 16\)。因此正确答案是 D。

English

Let \(S_n\) be the sum of row \(n.\) Each entry in row \(n-1\) feeds the two entries just below it, and the fixed border numbers \(10\) and \(1\) exactly make up for the terms lost at the edges. So \(S_n = 2 S_{n-1}\) for \(n \ge 3.\) With \(S_2 = 11,\) this gives \(S_n = 11 \cdot 2^{n-2},\) so \(S_{11} = 11 \cdot 2^9 = 5632.\) Its digits sum to \(5 + 6 + 3 + 2 = 16.\) Thus, D is the correct answer.

4单选

七进位两位数 \(\underline{a}\,\underline{b}\) 的值等于九进位两位数 \(\underline{b}\,\underline{a}\) 的值。\(a + b\) 是多少？

English（选项同上方）

The value of the two-digit number \(\underline{a}\,\underline{b}\) in base seven equals the value of the two-digit number \(\underline{b}\,\underline{a}\) in base nine. What is \(a + b?\)

按位值，七进制的 \(\underline{a}\,\underline{b}\) 是 \(7a + b\)，九进制的 \(\underline{b}\,\underline{a}\) 是 \(9b + a\)。令两者相等：\(7a + b = 9b + a\)，所以 \(6a = 8b\)，即 \(3a = 4b\)。因此 \(a = 4t\)，且 \(b = 3t\)。因为它们是两位数，\(t \ne 0\)；又因为 \(a\) 是七进制数字，所以 \(t \le 1\)。因此 \(a = 4\)、\(b = 3\)，所以 \(a + b = 7\)。所以答案是 A。

English

By place value, \(\underline{a}\,\underline{b}\) in base seven is \(7a + b,\) and \(\underline{b}\,\underline{a}\) in base nine is \(9b + a.\) Set them equal: \(7a + b = 9b + a,\) so \(6a = 8b,\) that is \(3a = 4b.\) Thus \(a = 4t\) and \(b = 3t.\) Because these are two-digit numerals, \(t \ne 0;\) because \(a\) is a base-seven digit, \(t \le 1.\) Hence \(a = 4\) and \(b = 3,\) so \(a + b = 7.\) Therefore, the answer is A.

5单选

在 \(\triangle ABC\) 中，\(AB = 10\)、\(AC = 18\)、\(\angle B = 130^\circ\)。设 \(O\) 是经过 \(A\)、\(B\)、\(C\) 三点的圆的圆心。求 \(\angle CAO\) 的度数。

English（选项同上方）

In \(\triangle ABC,\) \(AB = 10,\) \(AC = 18,\) and \(\angle B = 130^\circ.\) Let \(O\) be the center of the circle containing points \(A,\) \(B,\) and \(C.\) What is the degree measure of \(\angle CAO?\)

因为 \(O\) 是外心，\(OA = OB = OC\)。圆周角 \(\angle B = 130^\circ\) 对应弧 \(AC\)，且由于 \(B\) 是钝角，对应的小圆心角为 \(\angle AOC = 360^\circ\) \(- 2 \cdot 130^\circ = 100^\circ\)。三角形 \(OAC\) 是等腰三角形，所以 \(\angle CAO = \tfrac{180^\circ - 100^\circ}{2} = 40^\circ\)。边长 \(AB\) 和 \(AC\) 实际上不需要用到。因此正确答案是 C。

English

Since \(O\) is the circumcenter, \(OA = OB = OC.\) The inscribed angle \(\angle B = 130^\circ\) subtends arc \(AC,\) and because \(B\) is obtuse, the central angle is \(\angle AOC = 360^\circ\) \(- 2 \cdot 130^\circ = 100^\circ.\) Triangle \(OAC\) is isosceles, so \(\angle CAO = \tfrac{180^\circ - 100^\circ}{2} = 40^\circ.\) (The lengths \(AB\) and \(AC\) never enter.) Thus, C is the correct answer.

6单选

直线 \(y = \tfrac{1}{3}x + 1\) 把由 \(0 \le x \le 2\) 和 \(0 \le y \le 2\) 定义的正方形区域分成上、下两部分。直线 \(x = a\) 又把下方区域分成面积相等的两部分。若 \(a\) 可以写成 \(\sqrt{s} - t\)，其中 \(s\) 和 \(t\) 是正整数，求 \(s + t\)。

English（选项同上方）

The line \(y = \tfrac{1}{3}x + 1\) divides the square region defined by \(0 \le x \le 2\) and \(0 \le y \le 2\) into an upper region and a lower region. The line \(x = a\) divides the lower region into two regions of equal area. Then \(a\) can be written as \(\sqrt{s} - t,\) where \(s\) and \(t\) are positive integers. What is \(s + t?\)

下方区域的面积为 \(\int_0^2\left(\tfrac{x}{3} + 1\right)dx = \tfrac{2}{3} + 2 = \tfrac{8}{3}\)。\(0 \le x \le a\) 的部分是面积为 \(a + \tfrac{a^2}{6}\) 的梯形。它应等于总面积的一半，即 \(\tfrac{4}{3}\)，所以 \(a^2 + 6a - 8 = 0\)，从而 \(a = -3 + \sqrt{17}\)。因此 \(s = 17\)，\(t = 3\)，\(s + t = 20\)。因此正确答案是 C。

English

The lower region has area \(\int_0^2\left(\tfrac{x}{3} + 1\right)dx = \tfrac{2}{3} + 2 = \tfrac{8}{3}.\) The slice with \(0 \le x \le a\) is a trapezoid of area \(a + \tfrac{a^2}{6}.\) We want that to be half the total, namely \(\tfrac{4}{3},\) so \(a^2 + 6a - 8 = 0\) and \(a = -3 + \sqrt{17}.\) Then \(s = 17,\) \(t = 3,\) and \(s + t = 20.\) Therefore, the answer is C.

7单选

Frances 站在一扇上锁的门正南方 \(15\) 米处，这扇门位于一条东西走向的栅栏上。栅栏正后方有一盒巧克力，位于上锁的门以东 \(x\) 米处。另有一扇未上锁的门位于巧克力盒以东 \(9\) 米处，还有一扇未上锁的门位于上锁的门以西 \(8\) 米处。Frances 可以走向一扇未上锁的门，穿过它，再走向巧克力盒。碰巧无论经由哪一扇未上锁的门，她走的总距离都相同。求 \(x\)？

English（选项同上方）

Frances stands \(15\) meters directly south of a locked gate in a fence that runs east-west. Immediately behind the fence is a box of chocolates, located \(x\) meters east of the locked gate. An unlocked gate lies \(9\) meters east of the box, and another unlocked gate lies \(8\) meters west of the locked gate. Frances can reach the box by walking toward an unlocked gate, passing through it, and walking toward the box. It happens that the total distance Frances would travel would be the same via either unlocked gate. What is the value of \(x?\)

把栅栏放在 \(x\)-轴上，上锁的门在原点，Frances 在 \((0, -15)\)。则盒子在 \((x, 0)\)，东门在 \((x + 9, 0)\)，西门在 \((-8, 0)\)。东侧路线为 \(\sqrt{(x + 9)^2 + 15^2} + 9\)；西侧路线为 \(\sqrt{8^2 + 15^2}\) \(+ (x + 8) = 17 + x + 8\)。令二者相等，得 \(\sqrt{(x + 9)^2 + 225} = x + 16\)。平方并化简：\(18x + 306 = 32x + 256\)，所以 \(x = \tfrac{50}{14} = \tfrac{25}{7} = 3\tfrac{4}{7}\)。因此正确答案是 C。

English

Put the fence on the \(x\)-axis, the locked gate at the origin, and Frances at \((0, -15).\) Then the box is at \((x, 0),\) the east gate at \((x + 9, 0),\) and the west gate at \((-8, 0).\) The east route is \(\sqrt{(x + 9)^2 + 15^2} + 9;\) the west route is \(\sqrt{8^2 + 15^2}\) \(+ (x + 8) = 17 + x + 8.\) Set them equal: \(\sqrt{(x + 9)^2 + 225} = x + 16.\) Square and simplify to get \(18x + 306 = 32x + 256,\) so \(x = \tfrac{50}{14} = \tfrac{25}{7} = 3\tfrac{4}{7}.\) Thus, C is the correct answer.

8单选

Emmy 对 Max 说：“我今天订了 \(36\) 件数学俱乐部运动衫。”Max 问：“每件多少钱？”Emmy 回答：“我给你一个提示。总价是 \(\$\underline{A}\,\underline{B}\,\underline{B}.\underline{B}\,\underline{A}\)，其中 \(A\) 和 \(B\) 是数字，且 \(A \ne 0\)。”停顿片刻后，Max 说：“这个价格不错。”求 \(A + B\)。

English（选项同上方）

Emmy says to Max, “I ordered \(36\) math club sweatshirts today.” Max asks, “How much did each shirt cost?” Emmy responds, “I’ll give you a hint. The total cost was \(\$\underline{A}\,\underline{B}\,\underline{B}.\underline{B}\,\underline{A},\) where \(A\) and \(B\) are digits and \(A \ne 0.\)” After a pause, Max says, “That was a good price.” What is \(A + B?\)

以美分为单位，总价是 \(10000A + 1000B + 100B\) \(+ 10B + A\) \(= 10001A + 1110B\)。它要平均分给 \(36\) 件运动衫，所以能被 \(36\) 整除。因为 \(10001 \equiv 29\) 且 \(1110 \equiv 30 \pmod{36}\)，所以需要 \(29A + 30B \equiv 0\)，也就是 \(7A + 6B \equiv 0 \pmod{36}\)。在 \(A \ne 0\) 的数字解中，唯一可行的是 \(A = 6, B = 5\)，因为 \(7 \cdot 6 + 6 \cdot 5 = 72\)。这对应 \(\$655.56\)，也就是每件 \(\$18.21\)，所以 \(A + B = 11\)。因此正确答案是 C。

English

In cents the total is \(10000A + 1000B + 100B\) \(+ 10B + A\) \(= 10001A + 1110B.\) Split evenly among \(36\) shirts, so it’s divisible by \(36.\) Now \(10001 \equiv 29\) and \(1110 \equiv 30 \pmod{36},\) so we need \(29A + 30B \equiv 0,\) which reduces to \(7A + 6B \equiv 0 \pmod{36}.\) The only digit solution with \(A \ne 0\) is \(A = 6, B = 5,\) since \(7 \cdot 6 + 6 \cdot 5 = 72.\) That’s \(\$655.56,\) or \(\$18.21\) a shirt, so \(A + B = 11.\) Therefore, the answer is C.

9单选

有多少个整数有序三元组 \((x, y, z)\) 满足下面的不等式组？

\[-x - y - z \le -2\] \[-x + y + z \le 2\] \[x - y + z \le 2\] \[x + y - z \le 2\]

English（选项同上方）

How many ordered triples of integers \((x, y, z)\) satisfy the following system of inequalities?

\[-x - y - z \le -2\] \[-x + y + z \le 2\] \[x - y + z \le 2\] \[x + y - z \le 2\]

令 \(p = -x + y + z\)，\(q = x - y + z\)，\(r = x + y - z\)。后三个不等式给出 \(p, q, r \le 2\)，第一个不等式给出 \(x + y + z \ge 2\)，并且 \(p + q + r = x + y + z\)。又因为 \(x = \tfrac{q + r}{2}\) 等，所以 \(p, q, r\) 必须同奇偶。现在数每项 \(\le 2\)、同奇偶、总和在 \([2, 6]\) 中的三元组。偶数情形有 \((2,2,2)\)、\((2,2,0)\) 的排列、\((2,0,0)\) 的排列，以及 \((2,2,-2)\) 的排列，共 \(10\) 个。奇数情形只有 \((1,1,1)\)。总共 \(11\) 个，并且每个都对应唯一的 \((x, y, z)\)。因此正确答案是 C。

English

Let \(p = -x + y + z,\) \(q = x - y + z,\) \(r = x + y - z.\) The last three inequalities say \(p, q, r \le 2,\) the first says \(x + y + z \ge 2,\) and \(p + q + r = x + y + z.\) Since \(x = \tfrac{q + r}{2}\) and so on, \(p, q, r\) must all share the same parity. Now count triples with each part \(\le 2,\) equal parity, and sum in \([2, 6].\) The even ones are \((2,2,2),\) the permutations of \((2,2,0),\) of \((2,0,0),\) and of \((2,2,-2),\) giving \(10.\) The only odd one is \((1,1,1).\) That’s \(11\) in all, and each yields a unique \((x, y, z).\) Thus, C is the correct answer.

10单选

设 \(f(n) = n^3 - 5n^2 + 2n + 8\)，\(g(n) = n^3 - 6n^2 + 5n + 12\)。使 \(\dfrac{f(n)}{g(n)}\) 也为整数的所有整数 \(n\) 之和是多少？

English（选项同上方）

Let \(f(n) = n^3 - 5n^2 + 2n + 8,\) and let \(g(n) = n^3 - 6n^2 + 5n + 12.\) What is the sum of all integer values of \(n\) for which \(\dfrac{f(n)}{g(n)}\) is also an integer?

分解因式：\(f(n) = (n + 1)(n - 2)(n - 4)\)，\(g(n) = (n + 1)(n - 3)(n - 4)\)。避开 \(n \in \{-1, 3, 4\}\) 这些使 \(g\) 为零或出现 \(\tfrac{0}{0}\) 的值后，可约去公因式：\(\dfrac{f(n)}{g(n)} = \dfrac{n - 2}{n - 3} = 1 + \dfrac{1}{n - 3}\)。这只有在 \(n - 3 = \pm 1\) 时才是整数，所以 \(n = 2\) 或 \(n = 4\)。但 \(n = 4\) 使 \(g\) 为零，因此只有 \(n = 2\)，和为 \(2\)。因此正确答案是 A。

English

Factor both cubics: \(f(n) = (n + 1)(n - 2)(n - 4)\) and \(g(n) = (n + 1)(n - 3)(n - 4).\) Away from \(n \in \{-1, 3, 4\},\) where \(g\) vanishes or the ratio is \(\tfrac{0}{0},\) the common factors cancel and \(\dfrac{f(n)}{g(n)} = \dfrac{n - 2}{n - 3} = 1 + \dfrac{1}{n - 3}.\) That’s an integer only when \(n - 3 = \pm 1,\) so \(n = 2\) or \(n = 4.\) But \(n = 4\) kills \(g,\) so only \(n = 2\) survives, and the sum is \(2.\) Therefore, the answer is A.

11单选

星期一，\(6\) 名学生同时来到辅导中心，每人随机分配给当天值班的 \(6\) 名导师之一。星期二，同样的 \(6\) 名学生又来了，同样的 \(6\) 名导师也在值班，学生再次随机分配给导师。恰有 \(2\) 名学生两天都见到同一位导师的概率是多少？

English（选项同上方）

On Monday, \(6\) students went to the tutoring center at the same time, and each one was randomly assigned to one of the \(6\) tutors on duty. On Tuesday, the same \(6\) students showed up, the same \(6\) tutors were on duty, and the students were again randomly assigned to the tutors. What is the probability that exactly \(2\) students met with the same tutor both Monday and Tuesday?

每天的分配都是把 \(6\) 名学生分给 \(6\) 名导师的一个排列。比较两天时，保持同一导师的学生数就是 \(\tau = \pi_{\text{Tue}}^{-1}\pi_{\text{Mon}}\) 的不动点个数，而这个置换是 \(6\) 个元素上的均匀随机排列。要恰有 \(2\) 个不动点，先选出这 \(2\) 个，有 \(\binom{6}{2}\) 种；其余 \(4\) 个要错排，有 \(D_4 = 9\) 种。因此概率为 \(\dfrac{\binom{6}{2} D_4}{6!} = \dfrac{15 \cdot 9}{720} = \dfrac{3}{16}\)。所以正确答案是 B。

English

Each day’s assignment is a permutation of the \(6\) students among the \(6\) tutors. Comparing the two days, the number who keep the same tutor is the number of fixed points of \(\tau = \pi_{\text{Tue}}^{-1}\pi_{\text{Mon}},\) itself a uniformly random permutation of \(6\) elements. We want exactly \(2\) fixed points, so choose those \(2\) in \(\binom{6}{2}\) ways and derange the other \(4,\) where \(D_4 = 9.\) The probability is \(\dfrac{\binom{6}{2} D_4}{6!} = \dfrac{15 \cdot 9}{720} = \dfrac{3}{16}.\) Thus, B is the correct answer.

12单选

下图显示了一个等边三角形、一个有 \(60^\circ\) 角的菱形和一个正六边形。每个图形中都放有一些两两相切的全等圆盘。分别令 \(T\)、\(R\)、\(H\) 表示每种情况下圆盘总面积与外部多边形面积之比。

下列哪一项正确？

English（选项同上方）

The figure below shows an equilateral triangle, a rhombus with a \(60^\circ\) angle, and a regular hexagon, each of them containing some mutually tangent congruent disks. Let \(T,\) \(R,\) and \(H,\) respectively, denote the ratio in each case of the total area of the disks to the area of the enclosing polygon.

Which of the following is true?

设三角形边长为 \(s\)。三个半径为 \(r\) 的圆盘给出 \(s = 2r(1 + \sqrt3)\)，所以 \(T = \dfrac{3\pi r^2}{(\frac{\sqrt3}{4})s^2}\) \(= \dfrac{(2\sqrt3 - 3)\pi}{2} \approx 0.73\)。对于边长为 \(a\) 的菱形，两个圆盘位于长对角线上，满足 \(a\sqrt3 = 6r\)，所以 \(r = \tfrac{a}{2\sqrt3}\)，且 \(R = \dfrac{2\pi r^2}{(\frac{a^2\sqrt3}{2})} = \dfrac{\pi\sqrt3}{9} \approx 0.60\)。对于边长为 \(a\) 的正六边形，六个圆盘中每个都与一条边在中点处相切，同样有 \(r = \tfrac{a}{2\sqrt3}\)，且 \(H = \dfrac{6\pi r^2}{(\frac{3\sqrt3}{2})a^2}\) \(= \dfrac{\pi\sqrt3}{9} \approx 0.60\)。因此 \(H = R \lt T\)，正确答案是 C。

English

Take the triangle with side \(s.\) Three disks of radius \(r\) give \(s = 2r(1 + \sqrt3),\) so \(T = \dfrac{3\pi r^2}{(\frac{\sqrt3}{4})s^2}\) \(= \dfrac{(2\sqrt3 - 3)\pi}{2} \approx 0.73.\) For the rhombus with side \(a,\) the two disks sit on the long diagonal \(a\sqrt3 = 6r,\) so \(r = \tfrac{a}{2\sqrt3}\) and \(R = \dfrac{2\pi r^2}{(\frac{a^2\sqrt3}{2})} = \dfrac{\pi\sqrt3}{9} \approx 0.60.\) For the hexagon with side \(a,\) each of the six disks touches a side at its midpoint, again giving \(r = \tfrac{a}{2\sqrt3}\) and \(H = \dfrac{6\pi r^2}{(\frac{3\sqrt3}{2})a^2}\) \(= \dfrac{\pi\sqrt3}{9} \approx 0.60.\) So \(H = R \lt T.\) Therefore, the answer is C.

在第 \(i\) 行第 \(j\) 列，Horace 写的是 \(91(i - 1) + j\)，Vera 写的是 \(141(j - 1) + i\)。令二者相等并化简，得到 \(9i - 14j = -5\)，所以 \(i = \tfrac{14j - 5}{9}\)，恰好在 \(j \equiv 1 \pmod 9\) 时为整数。对于 \(j = 1, 10, 19, \ldots, 91\)，共有 \(11\) 个值，且对应的 \(i\) 为 \(1, 15, 29, \ldots, 141\)，都在范围内。因此有 \(11\) 个小正方形匹配，正确答案是 C。

English

At row \(i,\) column \(j,\) Horace writes \(91(i - 1) + j\) and Vera writes \(141(j - 1) + i.\) Set them equal and simplify to get \(9i - 14j = -5,\) so \(i = \tfrac{14j - 5}{9},\) an integer exactly when \(j \equiv 1 \pmod 9.\) For \(j = 1, 10, 19, \ldots, 91,\) that’s \(11\) values, and \(i\) runs \(1, 15, 29, \ldots, 141,\) all within range. So \(11\) squares match. Thus, C is the correct answer.

一只青蛙按如下规则在数轴上跳跃。它从 \(0\) 开始。如果它在 \(0\)，那么它以概率 \(\tfrac12\) 移动到 \(1\)，并以概率 \(\tfrac12\) 消失。对于 \(n = 1\)，\(2\) 或 \(3\)，如果它在 \(n\)，那么它以概率 \(\tfrac14\) 移动到 \(n + 1\)，以概率 \(\tfrac14\) 移动到 \(n - 1\)，并以概率 \(\tfrac12\) 消失。

青蛙到达 \(4\) 的概率是多少？

English（选项同上方）

A frog hops along the number line according to the following rules. It starts at \(0.\) If it is at \(0,\) then it moves to \(1\) with probability \(\tfrac12\) and it disappears with probability \(\tfrac12.\) For \(n = 1,\) \(2,\) or \(3,\) if it is at \(n,\) then it moves to \(n + 1\) with probability \(\tfrac14,\) it moves to \(n - 1\) with probability \(\tfrac14,\) and it disappears with probability \(\tfrac12.\)

What is the probability that the frog reaches \(4?\)

令 \(p_n\) 为从位置 \(n\) 出发到达 \(4\) 的概率，且 \(p_4 = 1\)。规则给出 \(p_0 = \tfrac12 p_1\)、\(p_1 = \tfrac14 p_0 + \tfrac14 p_2\)、\(p_2 = \tfrac14 p_1 + \tfrac14 p_3\)、\(p_3 = \tfrac14 p_2 + \tfrac14\)。向上求解可得 \(p_1 = \tfrac27 p_2\) 和 \(p_2 = \tfrac{7}{26} p_3\)。继续代回得到 \(p_3 = \tfrac{26}{97}\)、\(p_2 = \tfrac{7}{97}\)、\(p_1 = \tfrac{2}{97}\)，最后 \(p_0 = \tfrac{1}{97}\)。因此正确答案是 E。

English

Let \(p_n\) be the probability of reaching \(4\) from position \(n,\) with \(p_4 = 1.\) The rules give \(p_0 = \tfrac12 p_1,\) \(p_1 = \tfrac14 p_0 + \tfrac14 p_2,\) \(p_2 = \tfrac14 p_1 + \tfrac14 p_3,\) and \(p_3 = \tfrac14 p_2 + \tfrac14.\) Work upward: \(p_1 = \tfrac27 p_2\) and \(p_2 = \tfrac{7}{26} p_3.\) These unwind to \(p_3 = \tfrac{26}{97},\) \(p_2 = \tfrac{7}{97},\) \(p_1 = \tfrac{2}{97},\) and finally \(p_0 = \tfrac{1}{97}.\) Therefore, the answer is E.

正方形 \(ABCD\) 的边长为 \(4\)。点 \(P\) 和 \(Q\) 分别在 \(\overline{AD}\) 和 \(\overline{CD}\) 上，且 \(AP = \tfrac{8}{5}\)、\(DQ = \tfrac{10}{3}\)。一条路径从 \(P\) 到 \(Q\) 的线段开始，之后在正方形 \(ABCD\) 的边上反射继续前进（入射角等于反射角），如下图所示。如果路径碰到正方形的顶点，就在那里终止；否则它将永远继续。

这条路径会在哪个顶点终止？

English（选项同上方）

Square \(ABCD\) has sides of length \(4.\) Points \(P\) and \(Q\) lie on \(\overline{AD}\) and \(\overline{CD},\) respectively, with \(AP = \tfrac{8}{5}\) and \(DQ = \tfrac{10}{3}.\) A path begins along the line segment from \(P\) to \(Q\) and continues by reflecting against the sides of \(ABCD\) (with congruent incoming and outgoing angles), as shown in the figure. If the path hits a vertex of the square, then it terminates there; otherwise it continues forever.

At which vertex does the path terminate?

令 \(A = (0,0)\)、\(B = (4,0)\)、\(C = (4,4)\)、\(D = (0,4)\)，则 \(P = \left(0, \tfrac85\right)\)、\(Q = \left(\tfrac{10}{3}, 4\right)\)。初始方向为 \(\left(\tfrac{10}{3}, \tfrac{12}{5}\right) \parallel (25, 18)\)。把台球路径展开成由反射正方形拼成的网格，并从 \(P\) 出发沿直线前进。在网格顶点 \((4a,4b)\) 处，由横坐标得 \(t = \tfrac{4a}{25}\)。于是纵坐标要求 \(10 + 18a = 25b\)，即 \(a \equiv 5 \pmod{25}\)。第一个正的可能值是 \(a = 5\)，由此得 \(b = 4\)，展开后的顶点为 \((20,16)\)。横向穿过 \(5\) 个小正方形（奇数），说明它落在 \(x = 4\) 这条边上；纵向穿过 \(4\) 个小正方形（偶数），说明它落在 \(y = 0\) 上。这个顶点就是 \((4,0) = B\)。因此正确答案是 B。

English

Place \(A = (0,0),\) \(B = (4,0),\) \(C = (4,4),\) \(D = (0,4),\) so \(P = \left(0, \tfrac85\right)\) and \(Q = \left(\tfrac{10}{3}, 4\right).\) The initial direction is \(\left(\tfrac{10}{3}, \tfrac{12}{5}\right) \parallel (25, 18).\) Unfold the billiard into a grid of reflected copies and follow the straight line from \(P.\) At a grid corner \((4a,4b),\) the horizontal coordinate gives \(t = \tfrac{4a}{25}.\) The vertical coordinate then requires \(10 + 18a = 25b,\) so \(a \equiv 5 \pmod{25}.\) The first positive possibility is \(a = 5,\) giving \(b = 4\) and the unfolded corner \((20,16).\) Crossing \(5\) cells across (odd) puts it on the side \(x = 4,\) and \(4\) cells up (even) puts it on \(y = 0.\) That’s vertex \((4,0) = B.\) Thus, B is the correct answer.
