令 \(n=\lfloor x\rfloor\)。解必须为正，并满足 \[ \begin{aligned} x&=\sqrt{10n-\frac{51}{4}},\\ n&\le x\lt n+1\text{。} \end{aligned} \] 下界不等式等价于 \[ 4n^2-40n+51\le0\text{，} \] 所以 \(n=2,3,\ldots,8\)。上界不等式等价于 \[ 4n^2-32n+55\gt0\text{。} \] 在 \(2,\ldots,8\) 中，它恰对 \(n=2,6,7,8\) 成立。每个区间贡献一个根，所以共有四个实数解。

因此正确答案是 E。

English

Let \(n=\lfloor x\rfloor.\) A solution must be positive and satisfy \[ \begin{aligned} x&=\sqrt{10n-\frac{51}{4}},\\ n&\le x\lt n+1. \end{aligned} \] The lower inequality is equivalent to \[ 4n^2-40n+51\le0, \] so \(n=2,3,\ldots,8.\) The upper inequality is equivalent to \[ 4n^2-32n+55\gt0. \] Among \(2,\ldots,8,\) this holds exactly for \(n=2,6,7,8.\) Each interval contributes one root, so there are four real solutions.

Therefore the correct answer is E.
