济南 2016年浙江省中学生天文奥林匹克竞赛预赛试题

【注意事项】请务必仔细阅读：

1.每位考生会拿到一张预赛试卷和一张答卷。试卷和答卷都需要逐题填写，并且填写的内容必须完全一致。试卷和答卷填写内容不一致的题目每题得-4分。

2.低年组考生只答本卷的01-30题，高年组考生只答06-35题。

3.本卷为闭卷考试，请答卷人按照自己的真实水平独立完成答卷，并认真、完整地用签字笔在答卷上填写有关信息、选择试卷类型（见本注意事项之前的第二项：组别），并在相应题号下书写每道题的答案。未按要求填涂的取消考试成绩。考试开始30分钟之后才可交卷，并在不影响其他考试答题的情况下安静离开考场，否则取消考试成绩。在监考老师宣布考试结束时，该考场所有考生应停止答卷，将试卷和答卷放在桌上，保持安静离开考场。

4.每题选择一个最接近正确的答案。将对应的字母（A,B,C,D之一）填在试卷上并填涂在答卷该题号下方的对应出。不会做的题目不选。已填涂的答案如需改正，请用橡皮将原答案尽量擦除干净。每道题答对得4分，答错或多选得-4分，不选得0分。满分120分。草稿可写在试卷"草稿区"处。

27 答案 B

马头星云是低温尘埃和气体对背景光的吸收。

28 答案 C

放大率=物镜焦距/目镜焦距，C选项放大率最大（2032/25≈81.3倍）。

29 答案 C

拍银河要兼顾进光量与星点不拖尾：按曝光量 ISO×t/f² 估算，A 为 400×30/2.8²≈1531、B 为 6400×1/1.4²≈3265、C 为 3200×5/2.8²≈2041、D 为 1600×10/4²=1000。B 的总曝光量虽大，但 1 秒曝光难以积累银河暗弱结构的信号且高 ISO 噪点严重；C 在兼顾曝光时间与光圈、ISO 之间最平衡，实际能得到细节最丰富、观感最亮的银河。故选C。

30 答案 A

太阳最终会演变为白矮星。

31 答案 C

C 项“初升的月亮看起来更大”是典型的“月亮错觉”，属心理（视觉）效应，与大气无关；A 是高阶视宁度（大气湍流）、B 是大气消光、D 是大气色差（大气棱镜色散），三者都由大气造成。故选C。

32 答案 C

50mm口径望远镜可见最暗约10等星。

33 答案 C

黄道光与太阳风无直接关系。

34 答案 B

飞船轨道半径 r=2000 km，月球半径 R=1737 km。地球方向可视为固定，飞船被月球遮挡的条件是它到地月连线的距离小于 R，即 r·sinθ<R，sinθ=1737/2000≈0.869，θ≈60.3°，遮挡总张角 2θ≈120.6°。占周期比例 120.6/360≈33.5%，中断时间≈2.2 h×0.335≈0.74 h≈44 分钟，与 45 分钟最接近，故选B。

35 答案 B

两个黑洞并合为约62倍太阳质量的黑洞。
