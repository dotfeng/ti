1

Kate 烤了一盘 \(20\) 英寸乘 \(18\) 英寸的玉米面包。玉米面包被切成 \(2\) 英寸乘 \(2\) 英寸的小块。这一盘共有多少块玉米面包？

A\(90\) B\(100\) C\(180\) D\(200\) E\(360\)

English

Kate bakes a \(20\)-inch by \(18\)-inch pan of cornbread. The cornbread is cut into pieces that measure \(2\) inches by \(2\) inches. How many pieces of cornbread does the pan contain?

(A) \(90\)(B) \(100\)(C) \(180\)(D) \(200\)(E) \(360\)

2

Sam 在 \(90\) 分钟内开了 \(96\) 英里。前 \(30\) 分钟他的平均速度是每小时 \(60\) 英里，第二个 \(30\) 分钟的平均速度是每小时 \(65\) 英里。最后 \(30\) 分钟他的平均速度是每小时多少英里？

A\(64\) B\(65\) C\(66\) D\(67\) E\(68\)

English

Sam drove \(96\) miles in \(90\) minutes. His average speed during the first \(30\) minutes was \(60\) mph (miles per hour), and his average speed during the second \(30\) minutes was \(65\) mph. What was his average speed, in mph, during the last \(30\) minutes?

(A) \(64\)(B) \(65\)(C) \(66\)(D) \(67\)(E) \(68\)

3

(A) \(2\)(B) \(3\)(C) \(4\)(D) \(6\)(E) \(24\)

逐题解析

1 答案 A

整盘面积为 \(20 \times 18 = 360\) 平方英寸。每小块面积为 \(2 \times 2 = 4\) 平方英寸。因此小块数为 \(\frac{360}{4} = 90\)。正确答案是 A。

English

The whole pan has area \(20 \times 18 = 360\) square inches. Each piece is \(2 \times 2 = 4\) square inches. So the number of pieces is \(\frac{360}{4} = 90.\) Thus, A is the correct answer.

2 答案 D

每段都是半小时。第一段行驶 \(60 \cdot \tfrac12 = 30\) 英里，第二段行驶 \(65 \cdot \tfrac12 = 32.5\) 英里。前两段共 \(62.5\) 英里，还剩 \(96 - 62.5 = 33.5\) 英里。最后半小时的速度为 \(\frac{33.5}{\tfrac12} = 67\) 英里每小时。因此正确答案是 D。

English

Each leg is half an hour. In the first, Sam drove \(60 \cdot \tfrac12 = 30\) miles; in the second, \(65 \cdot \tfrac12 = 32.5\) miles. That’s \(62.5\) miles so far. That leaves \(96 - 62.5 = 33.5\) miles for the last half hour, which is a speed of \(\frac{33.5}{\tfrac12} = 67\) mph. Therefore, the answer is D.

3 答案 B

乘积中数字的顺序以及两个乘积相加的顺序都不影响结果，所以只需考虑把四个数字分成两对。有三种分法：\(1\cdot2 + 3\cdot4 = 14\)、\(1\cdot3 + 2\cdot4 = 11\) 以及 \(1\cdot4 + 2\cdot3 = 10\)。因此可以得到 \(3\) 个不同的值。正确答案是 B。

English

Order inside a product doesn’t matter, and neither does the order we add the two products. So all that matters is how the four digits split into two pairs. There are three splits: \(1\cdot2 + 3\cdot4 = 14,\) \(1\cdot3 + 2\cdot4 = 11,\) and \(1\cdot4 + 2\cdot3 = 10.\) That’s \(3\) different values. Thus, B is the correct answer.

4 答案 B

三种不同的面面积是两两乘积 \(XY = 24\)、\(XZ = 48\)、\(YZ = 72\)，次序可以互换。三式相乘得 \((XYZ)^2 = 24 \cdot 48 \cdot 72 = 82944\)，所以 \(XYZ = 288\)。分别除以三个面面积，得到 \(Z = \frac{288}{24} = 12\)、\(Y = \frac{288}{48} = 6\) 和 \(X = \frac{288}{72} = 4\)，因此 \(X + Y + Z = 22\)。正确答案是 B。

English

The three distinct face areas are the pairwise products \(XY = 24,\) \(XZ = 48,\) \(YZ = 72\) in some order. Multiply all three: \((XYZ)^2 = 24 \cdot 48 \cdot 72 = 82944,\) so \(XYZ = 288.\) Now divide by each face area. We get \(Z = \frac{288}{24} = 12,\) \(Y = \frac{288}{48} = 6,\) and \(X = \frac{288}{72} = 4,\) so \(X + Y + Z = 22.\) Therefore, the answer is B.

5 答案 D

设 \(a = \lfloor x \rfloor\)。方程可写成 \(x^2 = 10{,}000(x - a)\) \(= 10{,}000\{x\}\)。因为 \(0 \le \{x\} < 1\)，所以 \(0 \le x^2 < 10{,}000\)，即 \(-100 < x < 100\)。在每个区间 \([a, a + 1)\) 上，函数 \(10{,}000x - x^2\) 从 \(10{,}000a - a^2\) 单调增加并趋近于但不取到 \(10{,}000(a+1) - (a+1)^2\)。它恰好在 \((a + 1)^2 < 10{,}000\) 时取到 \(10{,}000a\)。满足条件的整数为 \(-100 \le a \le 98\)，共 \(199\) 个。正确答案是 C。

English

Let \(a = \lfloor x \rfloor.\) The equation reads \(x^2 = 10{,}000(x - a)\) \(= 10{,}000\{x\},\) and since \(0 \le \{x\} < 1,\) this forces \(0 \le x^2 < 10{,}000,\) so \(-100 < x < 100.\) On each interval \([a, a + 1)\) the quantity \(10{,}000x - x^2\) increases from \(10{,}000a - a^2\) and approaches, but does not reach, \(10{,}000(a+1) - (a+1)^2.\) It hits \(10{,}000a\) exactly once precisely when \((a + 1)^2 < 10{,}000.\) That holds for the integers \(-100 \le a \le 98,\) which is \(199\) solutions. Thus, C is the correct answer.
