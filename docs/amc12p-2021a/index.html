• 没有紫色的蛇会减法，并且

A紫色的蛇会加法。 B紫色的蛇是开心的。 C会加法的蛇是紫色的。 D开心的蛇不是紫色的。 E开心的蛇不会减法。

English

• none of his purple snakes can subtract, and

Which of these conclusions can be drawn about Tom’s snakes?

(A) Purple snakes can add.(B) Purple snakes are happy.(C) Snakes that can add are purple.(D) Happy snakes are not purple.(E) Happy snakes can’t subtract.

令 \(V = (0, 0)\)，焦点 \(F = (0, f)\)，准线为 \(y = -f\)，其中 \(f = FV\)。抛物线上的点 \(A = (x, y)\) 满足 \(x^2 = 4fy\)，且 \(AF = y + f = 20\)，所以 \(y = 20 - f\)。又 \(AV^2 = x^2 + y^2 = 4fy + y^2\) \(= 441\)。

代入 \(y = 20 - f\)： \[ \begin{aligned} &4f(20 - f) + (20 - f)^2 = 441 \\ &\;\Longrightarrow\; 3f^2 - 40f + 41 = 0\text{。} \end{aligned} \] 由 Vieta 公式，两个可能的 \(f\) 值之和为 \(\dfrac{40}{3}\)。

因此，正确答案是 B。

English

Let \(V = (0, 0),\) focus \(F = (0, f),\) and directrix \(y = -f,\) where \(f = FV.\) A point \(A = (x, y)\) on the parabola satisfies \(x^2 = 4fy\) and \(AF = y + f = 20,\) so \(y = 20 - f.\) Also \(AV^2 = x^2 + y^2 = 4fy + y^2\) \(= 441.\)

Substituting \(y = 20 - f:\) \[ \begin{aligned} &4f(20 - f) + (20 - f)^2 = 441 \\ &\;\Longrightarrow\; 3f^2 - 40f + 41 = 0. \end{aligned} \] By Vieta’s formulas, the sum of the two possible values of \(f\) is \(\dfrac{40}{3}.\)

Thus, the correct answer is B.

21 答案 A

根为 \(z = 1\)，\(z = -1 \pm i\sqrt3\)，和 \(z = -2 \pm i\sqrt2\)，对应点 \((1, 0)\)，\((-1, \pm\sqrt3)\)，和 \((-2, \pm\sqrt2)\)。由于关于 \(x\)-轴对称，椭圆具有形式 \(Ax^2 + Cy^2 + Dx + F = 0\)。

代入这些点得到 \(5x^2 + 6y^2 + 9x - 14 = 0\)。配方得 \[ 5\left(x + \tfrac{9}{10}\right)^2 + 6y^2 = \tfrac{361}{20}\text{，} \] 所以 \(a^2 = \tfrac{361}{100}\)（沿 \(x\) 方向），且 \(b^2 = \tfrac{361}{120}\)。于是 \(e^2 = 1 - \dfrac{b^2}{a^2} = 1 - \dfrac{100}{120} = \dfrac16\)，所以 \(e = \sqrt{\tfrac16}\)。

因此 \(m = 1\)，\(n = 6\)，得 \(m + n = 7\)。

因此，正确答案是 A。

English

The roots are \(z = 1,\) \(z = -1 \pm i\sqrt3,\) and \(z = -2 \pm i\sqrt2,\) giving the points \((1, 0),\) \((-1, \pm\sqrt3),\) and \((-2, \pm\sqrt2).\) By symmetry about the \(x\)-axis, the ellipse has the form \(Ax^2 + Cy^2 + Dx + F = 0.\)

Substituting the points yields \(5x^2 + 6y^2 + 9x - 14 = 0.\) Completing the square gives \[ 5\left(x + \tfrac{9}{10}\right)^2 + 6y^2 = \tfrac{361}{20}, \] so \(a^2 = \tfrac{361}{100}\) (along \(x\)) and \(b^2 = \tfrac{361}{120}.\) Then \(e^2 = 1 - \dfrac{b^2}{a^2} = 1 - \dfrac{100}{120} = \dfrac16,\) so \(e = \sqrt{\tfrac16}.\)

With \(m = 1\) and \(n = 6,\) we get \(m + n = 7.\)

Thus, the correct answer is A.

22 答案 D

设三个根为 \(r_1,r_2,r_3\)。由七次单位根可得 \(r_1+r_2+r_3=-\tfrac12\)。把这三个角都加倍只是把它们的余弦值重新排列，所以 \(\sum r_i^2=\tfrac32+\tfrac12\sum r_i=\tfrac54\)。于是 \(r_1r_2+r_1r_3+r_2r_3\) 等于 \(\tfrac12((\sum r_i)^2-\sum r_i^2)=-\tfrac12\)。

由积化和差公式得 \(4r_1r_2r_3=1+r_1+r_2+r_3=\tfrac12\)，所以 \(r_1r_2r_3=\tfrac18\)。因此它们的首一多项式为 \[ x^3 + \tfrac12 x^2 - \tfrac12 x - \tfrac18 = 0\text{。}\]

对比系数得 \(a = \tfrac12\)，\(b = -\tfrac12\)，\(c = -\tfrac18\)。因此 \(abc = \tfrac12\cdot\left(-\tfrac12\right)\cdot\left(-\tfrac18\right) = \tfrac{1}{32}\)。

因此，正确答案是 D。

English

Let the three roots be \(r_1,r_2,r_3.\) The seventh roots of unity give \(r_1+r_2+r_3=-\tfrac12.\) Doubling the three angles merely permutes their cosines, so \(\sum r_i^2=\tfrac32+\tfrac12\sum r_i=\tfrac54.\) Hence \(r_1r_2+r_1r_3+r_2r_3\) equals \(\tfrac12((\sum r_i)^2-\sum r_i^2)=-\tfrac12.\)

The product-to-sum identity gives \(4r_1r_2r_3=1+r_1+r_2+r_3=\tfrac12,\) so \(r_1r_2r_3=\tfrac18.\) Therefore their monic polynomial is \[ x^3 + \tfrac12 x^2 - \tfrac12 x - \tfrac18 = 0. \]

Matching coefficients, \(a = \tfrac12,\) \(b = -\tfrac12,\) \(c = -\tfrac18.\) Therefore \(abc = \tfrac12\cdot\left(-\tfrac12\right)\cdot\left(-\tfrac18\right) = \tfrac{1}{32}.\)

Thus, the correct answer is D.

23 答案 D

将方格分为中心格 \(C\)、边中格 \(E\) 和角格（吸收状态）。从 \(C\) 出发，每一步都会到达一个 \(E\) 格。从一个 \(E\) 格出发，四个相邻格中有两个是角格，一个是中心格，一个是另一个 \(E\) 格，所以 \(P(\text{角格}) = \tfrac12\)、\(P(\text{中心格}) = \tfrac14\)、\(P(E) = \tfrac14\)。

设 \(a_n\) 为从边格出发、在 \(n\) 步内到达角格的概率，且 \(c_n\) 为从中心出发的概率（第一步必到边格）。于是 \(a_0=c_0=0\)，并且 \(c_n=a_{n-1}\)。计算得 \(a_n=\tfrac12+\tfrac14c_{n-1}+\tfrac14a_{n-1}\)，且 \(a_1=\tfrac12\)，\(a_2=\tfrac12+\tfrac14\cdot\tfrac12=\tfrac58\)，\[ a_3 = \tfrac12 + \tfrac14\cdot\tfrac12 + \tfrac14\cdot\tfrac58 = \tfrac{25}{32}\text{。}\]

从中心开始且有四步可用时，概率等于 \(a_3 = \tfrac{25}{32}\)（第一步到达边格，剩下三步）。

因此，正确答案是 D。

English

Classify squares as center \(C,\) edge-middle \(E,\) or corner (absorbing). From \(C,\) every hop lands on an \(E\) square. From an \(E\) square, two of the four neighbors are corners, one is the center, and one is another \(E\) square, so \(P(\text{corner}) = \tfrac12,\) \(P(\text{center}) = \tfrac14,\) \(P(E) = \tfrac14.\)

Let \(a_n\) be the probability of reaching a corner within \(n\) hops starting from an edge square, and let \(c_n\) be the corresponding probability from the center. Set \(a_0=c_0=0.\) Then \(c_n=a_{n-1}\) and \(a_n=\tfrac12+\tfrac14c_{n-1}+\tfrac14a_{n-1}.\) Thus \(a_1=\tfrac12,\) \(a_2=\tfrac12+\tfrac14\cdot\tfrac12=\tfrac58,\) and \[ a_3 = \tfrac12 + \tfrac14\cdot\tfrac12 + \tfrac14\cdot\tfrac58 = \tfrac{25}{32}. \]

Starting from the center with four hops available, the probability equals \(a_3 = \tfrac{25}{32}\) (the first hop reaches an edge, leaving three hops).

Thus, the correct answer is D.

24 答案 D

在圆 \(\Omega\) 中，弦 \(QR\) 所对的圆周角 \(\angle QPR = 60^\circ\)，所以 \(QR = 2r\sin 60^\circ\)，于是 \(3\sqrt3 = r\sqrt3\)，得 \(r = 3\)。

设 \(A = (-7, 0)\)、\(B = (7, 0)\)，且 \(\Gamma: x^2 + y^2 = 49\)（上半圆）。因为 \(\Omega\) 在 \(P = (p, 0)\) 处与 \(AB\) 相切，其圆心为 \((p, 3)\)。两个圆方程相减得到直线 \(QR\)，而圆心 \((p,3)\) 到 \(QR\) 的距离必须等于 \(r\cos 60^\circ = \tfrac32\)。这给出 \((p^2 - 31)^2 = 9p^2 + 81\)，所以 \(p^2 = 16\)（根 \(p^2 = 55\) 会使 \(P\) 在 \(AB\) 外）。

当 \(p^2 = 16\) 时，点 \(P\) 到直线 \(QR\) 的距离是 \(\dfrac{49 - p^2}{\sqrt{4p^2 + 36}} = \dfrac{33}{10}\)。因此 \[ \begin{aligned} [\triangle PQR] &= \tfrac12\cdot QR\cdot d \\ &= \tfrac12\cdot 3\sqrt3\cdot\tfrac{33}{10} \\ &= \frac{99\sqrt3}{20}\text{。} \end{aligned} \] 所以 \(a = 99\)、\(b = 3\)、\(c = 20\)，且 \(a + b + c = 122\)。

因此，正确答案是 D。

English

In circle \(\Omega,\) the chord \(QR\) subtends the inscribed angle \(\angle QPR = 60^\circ,\) so \(QR = 2r\sin 60^\circ,\) giving \(3\sqrt3 = r\sqrt3,\) hence \(r = 3.\)

Place \(A = (-7, 0),\) \(B = (7, 0),\) with \(\Gamma: x^2 + y^2 = 49\) (upper half). Since \(\Omega\) is tangent to \(AB\) at \(P = (p, 0),\) its center is \((p, 3).\) Subtracting the two circle equations gives the line \(QR,\) and the distance from the center \((p,3)\) to \(QR\) must equal \(r\cos 60^\circ = \tfrac32.\) This yields \((p^2 - 31)^2 = 9p^2 + 81,\) so \(p^2 = 16\) (the root \(p^2 = 55\) places \(P\) outside \(AB\)).

With \(p^2 = 16,\) the distance from \(P\) to line \(QR\) is \(\dfrac{49 - p^2}{\sqrt{4p^2 + 36}} = \dfrac{33}{10}.\) Thus \[ \begin{aligned} [\triangle PQR] &= \tfrac12\cdot QR\cdot d \\ &= \tfrac12\cdot 3\sqrt3\cdot\tfrac{33}{10} \\ &= \frac{99\sqrt3}{20}. \end{aligned} \] So \(a = 99,\) \(b = 3,\) \(c = 20,\) and \(a + b + c = 122.\)

Thus, the correct answer is D.

25 答案 E

因为 \(f(n) = \dfrac{d(n)}{n^{\frac{1}{3}}}\) 是乘法函数，它的值可按质数幂分解为各个 \(p^e\ \|\ n\) 所对应的项 \(\dfrac{e + 1}{p^{\frac{e}{3}}}\) 的乘积。我们分别最大化每一项。

设 \(g_p(e)=\dfrac{e+1}{p^{\frac{e}{3}}}\)，则 \(\dfrac{g_p(e+1)}{g_p(e)}=\dfrac{e+2}{e+1}p^{-\frac{1}{3}}\)。这个比值随 \(e\) 递减，所以只要看它第一次小于 \(1\) 的位置，就能确定唯一的最大值。由此得到：对 \(p=2\) 取 \(e=3\)；对 \(p=3\) 取 \(e=2\)；对 \(p=5,7\) 取 \(e=1\)；而对每个质数 \(p\ge11\) 取 \(e=0\)。

因此 \(N = 2^3\cdot 3^2\cdot 5\cdot 7 = 2520\)，其数字和为 \(2 + 5 + 2 + 0 = 9\)。

因此，正确答案是 E。

English

Since \(f(n) = \dfrac{d(n)}{n^{\frac{1}{3}}}\) is multiplicative, its value factors over prime powers as a product of terms \(\dfrac{e + 1}{p^{\frac{e}{3}}}\) for each prime power \(p^e\ \|\ n.\) We maximize each term separately.

If \(g_p(e)=\dfrac{e+1}{p^{\frac{e}{3}}},\) then \(\dfrac{g_p(e+1)}{g_p(e)}=\dfrac{e+2}{e+1}p^{-\frac{1}{3}}.\) This ratio decreases with \(e,\) so checking where it first falls below \(1\) finds the unique maximum. It gives \(e=3\) for \(p=2,\) \(e=2\) for \(p=3,\) \(e=1\) for \(p=5,7,\) and \(e=0\) for every prime \(p\ge11.\)

Hence \(N = 2^3\cdot 3^2\cdot 5\cdot 7 = 2520,\) whose digit sum is \(2 + 5 + 2 + 0 = 9.\)

Thus, the correct answer is E.
