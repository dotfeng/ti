逐题解析

1 答案 E

两两分组可得 \[ \begin{aligned} &(1-2) + (3-4) + \cdots \\ &\quad {}+ (97-98) + 99\text{。} \end{aligned} \] 共有 \(49\) 组，每组等于 \(-1\)，所以总和为 \(-49 + 99 = 50\)。

所以正确答案是 E。

English

Pairing consecutive terms gives \[ \begin{aligned} &(1-2) + (3-4) + \cdots \\ &\quad {}+ (97-98) + 99. \end{aligned} \] There are \(49\) pairs, each equal to \(-1,\) so the sum is \(-49 + 99 = 50.\)

Thus, the correct answer is E.

2 答案 A

边长为 \(1\) 和边长为 \(2\) 的等边三角形形状相同但大小不同，所以它们相似但不全等。每个等边三角形都是凸的、等角的（每个角都是 \(60^\circ\)），也是正多边形，因此唯一错误的命题是所有等边三角形都彼此全等。

所以正确答案是 A。

English

Equilateral triangles with side lengths \(1\) and \(2\) have the same shape but different sizes, so they are similar but not congruent. Every equilateral triangle is convex, equiangular (all angles \(60^\circ\)), and a regular polygon, so the only false statement is that they are all congruent.

Thus, the correct answer is A.

3 答案 E

设 \(O\) 为内切球和外接球的共同球心。从 \(O\) 把正四面体分成四个全等部分可知，外接球半径是内切球半径的 \(3\) 倍，所以外接球的体积是内切球体积 \(V\) 的 \(27\) 倍。

若其余四个小球之一的半径为 \(s\)，则它的球心到 \(O\) 的距离为 \(r+s\)；从 \(O\) 量起，这段距离同时又等于 \(3r-s\)，所以 \(s=r\)。这五个球的内部互不相交（中心球与其余四球分别相切），所以并集体积为 \(5V\)。概率为 \(\dfrac{5V}{27V} = \dfrac{5}{27} \approx 0.185\)，最接近 \(0.2\)。

所以正确答案是 C。

English

Let \(O\) be the common center of the inscribed and circumscribed spheres. Splitting the tetrahedron into four congruent pieces from \(O\) shows the circumradius is \(3\) times the inradius, so the circumscribed sphere has \(27\) times the inscribed sphere’s volume \(V.\)

If one of the four other small spheres has radius \(s,\) its center is \(r+s\) from \(O\) and also \(3r-s\) from \(O,\) so \(s=r.\) These five spheres have disjoint interiors (the central sphere is tangent to each of the other four), so their union has volume \(5V.\) The probability is \(\dfrac{5V}{27V} = \dfrac{5}{27} \approx 0.185,\) closest to \(0.2.\)

Thus, the correct answer is C.

30 答案 D

令 \(z = -33\)，方程变为 \(m^3 + n^3 + z^3 - 3mnz = 0\)，因式分解得 \[ \begin{aligned} &(m + n - 33) \\ &\quad {}\cdot \scriptsize\left(m^2 + n^2 + 33^2 - mn + 33m + 33n\right) \\ &= 0 \end{aligned}\text{。}\]

第二个因子等于 \(\scriptsize\tfrac12\big[(m - n)^2 + (m + 33)^2 + (n + 33)^2\big]\)，只在 \((m, n) = (-33, -33)\) 时为 \(0\)，且满足 \(mn \ge 0\)。

否则 \(m + n = 33\)。由 \(mn \ge 0\)，二者同为非负，得到 \((0, 33), (1, 32), \ldots, (33, 0)\)，共 \(34\) 对。总计 \(35\) 对。

所以正确答案是 D。

English

Writing \(z = -33,\) the equation becomes \(m^3 + n^3 + z^3 - 3mnz = 0,\) which factors as \[ \begin{aligned} &(m + n - 33) \\ &\quad {}\cdot \scriptsize\left(m^2 + n^2 + 33^2 - mn + 33m + 33n\right) \\ &= 0. \end{aligned} \]

The second factor equals \(\scriptsize\tfrac12\big[(m - n)^2 + (m + 33)^2 + (n + 33)^2\big],\) which is \(0\) only at \((m, n) = (-33, -33);\) this satisfies \(mn \ge 0.\)

Otherwise \(m + n = 33.\) With \(mn \ge 0\) both are nonnegative, giving \((0, 33), (1, 32), \ldots, (33, 0),\) which is \(34\) pairs. Together there are \(35\) solutions.

Thus, the correct answer is D.
